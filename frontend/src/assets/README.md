# Frontend Assets

This directory holds product visual assets for the rebuilt artifact studio. Asset names use lowercase kebab-case and should describe product meaning rather than generation technique.

Initial structure:

- `brand/` - product marks and app identity assets
- `icons/` - custom product icons that are not better served by a UI icon library
- `motion/` - future Lottie or timeline assets for run status and artifact generation
- `textures/` - workbench surfaces and paper/source textures
- `previews/` - placeholder or generated previews for artifact states and output types

Prompt briefs and generation notes live in `docs/ASSET_PROMPTS/`. Do not commit private course materials, real student names, API keys, or paid asset credentials.
