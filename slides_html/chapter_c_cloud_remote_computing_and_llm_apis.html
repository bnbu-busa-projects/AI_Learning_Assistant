Recall: Cloud Computing

Cloud computing means software and hardware resources are delivered over a network.

  • Users do not manage every machine directly.
  • Services can scale up or down.
  • Organizations pay for access, usage, or managed capability.

Why AI Uses Cloud Services

Compute

Large models require powerful hardware.

Data

Systems need storage, retrieval, and governance.

Model hosting

Organizations call hosted models instead of running everything locally.

Scaling

Services can handle more users and requests.

Cloud is not just a place. It is a service model for business systems.

AI Needs Remote Computing

  • Training models can require specialized hardware.
  • Serving models can require fast response at scale.
  • A lightweight laptop can use a powerful remote service.

What Is a Server?

A server is a computer or service that responds to requests from clients.

  • The client asks for something.
  • The server processes the request.
  • The server returns a response.

API Key

An API key is a secret credential used to identify and authorize a caller.

  • It is not a password for a person.
  • It grants access to a service account or project.
  • It should not be pasted into slides, notebooks, or public repositories.

What Is an LLM API?

An LLM API is a service that takes messages and returns model output.

  • Your app sends a request.
  • The model service generates a response.
  • The response may include usage metadata.

Anatomy of an LLM Request

{ "model": "example-model", "messages": [ {"role": "system", "content": "Be concise."}, {"role": "user", "content": "Summarize this table."} ], "temperature": 0.2, "max_output_tokens": 300 }

Anatomy of an LLM Response

{ "output_text": "The table shows...", "usage": { "input_tokens": 420, "output_tokens": 86 }, "status": "completed" }
The text is only one part of the response. Usage metadata also matters for cost and system design.

Tokens

Tokens are units used for input, output, context, and billing.

  • They are roughly pieces of text.
  • Longer prompts and longer outputs cost more.
  • Token limits affect how much context the model can use.

Latency is the time between request and response. It affects user experience and workflow design.

Reliability

  • API services can fail.
  • Services can slow down.
  • Responses can change if models or settings change.
  • Use status checks.
  • Plan fallbacks.
  • Log important assumptions.

Structured Output

Structured output asks the model to return machine-readable data.

{ "summary": "Sales increased in Q4.", "risk_level": "medium", "evidence": ["revenue trend", "order count"] }
Useful when AI output becomes part of another information system.
