What Is Cursor?

Cursor is an AI coding environment for working with code, notebooks, terminal commands, and project files.

  • Open a course project folder.
  • Ask the agent to inspect files.
  • Edit notebooks and scripts.
  • Run and debug analysis.

What Is an Agent in This Context?

  • It can read project files.
  • It can suggest an analysis plan.
  • It can edit code and notebook cells.
  • It can run commands and use error messages to debug.

The Human Analyst Is Still Responsible

Agent draftsAnalyst verifies
Suggests a planChecks whether the plan answers the business question
Writes codeConfirms row counts, formulas, and outputs
Explains chartsChecks whether the interpretation matches evidence
Debugs errorsDecides whether the fix is minimal and appropriate
The agent accelerates work. It does not own the conclusion.

Cursor Workflow Step 1

Ask the agent to inspect first. Do not ask for a full analysis immediately. Do not ask for final charts immediately. Do not accept code before you understand the dataset.
The first goal is orientation, not speed.

Good First Prompt

Inspect the CSV and summarize: 1. column names and likely meanings, 2. row and column count, 3. data types and missing or unknown values, 4. reasonable business questions, 5. a short analysis plan. Do not write analysis code until I confirm the plan.

Scope

Start with one dataset.

Control

Approve the plan before code.

Evidence

Data Quality Questions

  • Are values missing or marked as unknown?
  • Are there duplicate rows?
  • Are categories inconsistent?
  • Are there impossible values?
  • Did loading change the row count?
  • Do columns match the business story?
AI-generated summaries are useful only after these checks are performed.

Missing Values

Value patternPossible meaningClassroom decision
unknown in jobCustomer category not recordedKeep as a category and discuss
unknown in educationEducation unavailableDo not silently drop rows
Blank or NaNParsing or missing recordCount and inspect before deciding
Unknown is often information, not just an error.

Duplicates

Duplicate row

The exact same row appears more than once. This may be a data quality issue.

Repeated customer/contact

A real business process may contact similar customers many times.

Do not blindly drop rows just because the word "duplicate" appears in an AI answer.

Visualization Quality Rules

  • Use honest axes.
  • Use readable labels.
  • Use a title that states the question.
  • Do not hide sample size.
  • Do not overload categories.
  • Do not decorate instead of explaining.

Checkpoint 3: Chart Verification

Ask before accepting a chart:

  • What question does this chart answer?
  • Are the labels readable?
  • Is the calculation correct?
  • Could the chart be misleading?

A Critical Analytics Trap

duration is only known after the call.

If the goal is to decide whom to call before the campaign, then using call duration can leak information from the future.

Data Leakage in Plain English

Before call
age, job, balance
→
Call happens
→
After call
duration, outcome
A variable may look predictive because it is unavailable at decision time.

AI Agents Can Miss Business Context

  • The agent may optimize a technical metric.
  • The business decision may require a different metric.
  • The agent may include a leakage variable unless you tell it not to.

Common Error: Plot Too Crowded

Before

Every category appears, labels overlap, and the chart is hard to read.

After

Sort, limit to top categories, rotate labels only when necessary, and explain what was excluded.
