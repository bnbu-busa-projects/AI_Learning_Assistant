What Changed in the AI Era?

Natural language

Users can ask systems questions in ordinary language.

Automation

Systems can draft, summarize, classify, and suggest next steps.

Scale

Large volumes of text, code, and documents can be processed faster.

Personalization

Interfaces and recommendations can adapt to different users.

These are information-system changes, not just algorithm changes.

Supervised vs Unsupervised Learning

Type Beginner idea Business example
Supervised learning The data includes an outcome label. Predict churn using past customers labeled as stayed or left.
Unsupervised learning The system looks for patterns without a target label. Find customer segments from purchase behavior.
For this course, focus on what business question the method answers.

Generative AI

Generative AI creates draft outputs such as:

  • text and summaries
  • code and explanations
  • charts and analysis plans
  • images, messages, and alternatives
A generated draft is not automatically true.

What Is an LLM?

A large language model works with language patterns and context.

  • It receives text input.
  • It predicts and generates likely text output.
  • It can help with drafting, explaining, coding, and summarizing.

Plain English version

An LLM is a language-based engine for producing useful drafts from instructions and context.

It is powerful, but it does not automatically know what is true, private, current, or appropriate for your decision.

Agentic AI

An agentic AI system can use tools and take multi-step actions toward a goal.

  • read files
  • write or edit code
  • run commands
  • inspect results and suggest fixes

Agents Are Not Autonomous Employees

  • Agents need a clear goal.
  • Agents need constraints and relevant context.
  • Agents need human review before results become decisions.
Think of the agent as a fast draft partner, not the owner of accountability.

What AI Is Good At

Summarization

Turn long material into a first-pass brief.

Pattern spotting

Suggest relationships to investigate.

Drafting

Produce a starting version of messages, plans, and reports.

Code assistance

Help write, explain, and debug beginner code.

First-pass analysis

Propose tables, charts, and business questions.

Translation of intent

Move from natural language to structured actions.

What AI Struggles With

  • Factual reliability
  • Hidden assumptions
  • Current facts and changing policies
  • Private or sensitive data handling
  • Accountability for final decisions

A Simple Prompting Pattern

Inspect
→
Plan
→
Execute
→
Verify
→
Summarize
This pattern keeps the human in control of the workflow and makes mistakes easier to catch.

Example Prompt for Data Work

Inspect this dataset first. Do not write code yet. Tell me: 1. what each column appears to mean, 2. what data quality issues I should check, 3. which business questions are reasonable, 4. what analysis plan you recommend. Wait for my confirmation before generating code.

Inspect first

Avoid rushing into code.

Plan first

Align with the business question.

Confirm first

Keep the human responsible.

Classroom Rule for AI Tools

Use

  • public data
  • course-provided datasets
  • your own non-sensitive examples

Do not paste

  • student records
  • customer or employee data
  • passwords, keys, or private documents
If you are unsure whether data is safe to upload, stop and ask first.

Where could AI improve a business process you know, and what could go wrong?

Key Takeaways

AI is an IS capability

It belongs inside people, process, data, and technology.

Agents need supervision

They can use tools, but they do not own business judgment.

Verification matters

Generated output should be checked against evidence.
